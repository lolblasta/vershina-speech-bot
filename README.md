# 🗣 30 дней к чистой речи — Telegram-бот

Бот логопедического центра «Вершина». Продаёт курс из 30 ежедневных упражнений для развития речи ребёнка.

## Что умеет бот

- Онбординг: возраст → проблема → удобное время
- Автоматически подбирает один из 3 треков контента:
  - **Запуск речи** (1.5–3 года, мало говорит)
  - **Звук Р** (4–7 лет)
  - **Общее развитие речи** (2.5–5 лет)
- Принимает оплату через **ЮKassa** (490 ₽)
- Каждый день в выбранное время присылает задание
- Пользователь отмечает выполнение кнопкой
- Команды `/today`, `/progress`, `/help`
- Админ-команды `/stats`, `/broadcast`

## Быстрый запуск (Railway — бесплатно)

### 1. Создайте .env файл

Скопируйте `.env.example` → `.env` и заполните:

```env
BOT_TOKEN=ваш_токен_от_BotFather
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
ADMIN_IDS=ваш_telegram_id
PRICE_RUB=490
CHANNEL_URL=https://t.me/vershinamoskva
SUPPORT_URL=https://t.me/neurovershinaadmin
```

> **Где взять Telegram ID?** Напишите боту [@userinfobot](https://t.me/userinfobot)

### 2. Настройте ЮKassa

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru) как ИП или ООО
2. Создайте магазин → получите `Shop ID` и `Secret Key`
3. В настройках магазина: **Настройки API** → вставьте данные в `.env`

> Для тестирования используйте тестовый ключ: он начинается на `test_`

### 3. Деплой на Railway

1. Зайдите на [railway.app](https://railway.app) → "New Project" → "Deploy from GitHub repo"
2. Выберите этот репозиторий
3. Перейдите в **Variables** и добавьте все переменные из `.env`
4. Railway автоматически запустит бот по `Procfile`

✅ Готово! Бот работает 24/7 бесплатно на Railway.

## Редактирование контента

Все упражнения находятся в `content.py` в трёх списках:
- `TRACK_LAUNCH` — 30 упражнений для запуска речи
- `TRACK_SOUND_R` — 30 упражнений для звука Р  
- `TRACK_GENERAL` — 30 упражнений для общего развития

Каждое упражнение — словарь с полями `day`, `title`, `emoji`, `body`.
